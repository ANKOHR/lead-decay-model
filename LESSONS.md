# Lessons for KOML

The domain needs an explicit contact definition, snapshot date, and threshold policy before a cold label can be reproducible. Inactivity is observable from supplied dates; intent and conversion likelihood are not.

Validated by synthetic evidence: integer arithmetic and inclusive date thresholds reproduce all 200 planted classifications and reconcile opportunity values exactly. The adversarial mutation changes the output without changing ground truth, demonstrating computation rather than a static report. Broken assumption: passing synthetic tests establishes business usefulness. It only establishes implementation correctness; real usefulness and threshold calibration remain unmeasured.

Operating rule for future builds: specify the observable rule and provenance before creating scores, and separate software acceptance evidence from real-use evidence. Fix the largest measured disagreement after a hand-checked trial; kill unused tools rather than claiming hypothetical savings.
